An offline tracker and guide for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist with progress saved in the browser, filters by kind and grade, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, the missable trophies flagged, and a guide to each trophy in our own words that cites its sources. It runs entirely from its own files — no network, no account.

## Run it

```sh
python3 -m http.server 8000 --directory app
```

Then open http://localhost:8000 in a desktop browser. Export and import move your checklist progress as a JSON file.
